# KALPU PREMIUM STORE V2

Telegram digital-goods store + web admin dashboard for GitHub and Render.

## Features
- Telegram product catalogue and UPI QR generation.
- Customer submits UTR / transaction reference.
- Admin receives Telegram approval buttons.
- Web dashboard shows orders, UTRs, sales totals and status.
- Web admin can approve/reject orders.
- Approval triggers Telegram delivery.
- Products can be added from the web dashboard.
- SQLite database stored on Render persistent disk.
- Session-protected dashboard and CSRF-protected POST actions.

## Payment limitation
A static UPI ID, QR code, and customer-entered UTR do not provide trusted automatic payment confirmation. An admin must verify the incoming credit in their bank/UPI app and approve the order. Delivery is automatic immediately after approval.

For fully automatic bank-side confirmation, integrate a supported payment gateway/acquiring provider that sends signed payment webhooks. Never treat a screenshot or UTR string alone as proof of payment.

## Product/content rules
Use this store only for lawful digital goods and content you have the right to distribute. Do not list child sexual-abuse material, non-consensual intimate content, rape/exploitation material, stolen data, malware, or other illegal goods.

## Deploy to Render
1. Create a GitHub repository and upload all files in this folder.
2. In Render, choose New -> Blueprint and connect the repository.
3. Render reads render.yaml and creates the web service plus persistent disk.
4. Set BOT_TOKEN, ADMIN_ID, ADMIN_USERNAME, ADMIN_PASSWORD and UPI_ID.
5. SESSION_SECRET is generated by Render.
6. Deploy and open https://YOUR-RENDER-SERVICE.onrender.com/login.
7. Sign in and open Products to add your catalogue. Replace sample URLs before accepting orders.

## Telegram setup
1. Create a bot using @BotFather.
2. Copy its token into BOT_TOKEN.
3. Set ADMIN_ID to your numeric Telegram user ID.
4. Start the bot with /start.
5. Use /admin for a quick order summary.

## Local run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 10000
```

## Security / operations
- Use a strong, unique admin password.
- Keep bot token and UPI credentials out of GitHub.
- Use HTTPS.
- Keep the persistent disk attached; SQLite data is stored under /var/data.
- Back up the database regularly.
- Verify payment in your bank/UPI app before approving.
- Prefer private/controlled HTTPS delivery links.
